# РесурсБронь

РесурсБронь помогает студентам и сотрудникам учебной организации бронировать аудитории и оборудование. Пользователь видит свободное время, получает подтверждение и может сам отменить бронь. Ответственный за ресурс видит подтверждённые брони своего ресурса и отмечает фактическое использование.

## Первый семестр

- Поиск доступных ресурсов по типу и интервалу времени.
- Создание брони (Job) и автоматическая проверка пересечений, прав и лимита.
- Просмотр своих броней и их статусов, отмена до начала интервала.
- Отметка использования ответственным и автоматическое истечение срока.
- Уведомления по email о подтверждении, отмене и истечении подтверждённой брони. Внешняя зависимость — почтовый сервис. Состояние брони хранится в РесурсБрони и доступно при сбое отправки.

Каталог ресурсов, часы доступности и роли заданы заранее. В первый семестр за рамками проекта остаются управление каталогом через интерфейс, ручное согласование, перенос и повторяющиеся брони, синхронизация с внешними календарями.
