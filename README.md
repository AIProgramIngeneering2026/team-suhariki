# РесурсБронь

РесурсБронь помогает студентам и сотрудникам учебной организации бронировать аудитории и оборудование. Пользователь видит свободное время, получает подтверждение и может сам отменить бронь. Ответственный за ресурс видит подтверждённые брони своего ресурса и отмечает фактическое использование.

## Первый семестр

- Поиск доступных ресурсов по типу и интервалу времени.
- Создание брони (Job) и асинхронная проверка прав, расписания, пересечений и лимита.
- Просмотр своих броней и их статусов, отмена до начала интервала.
- Отметка использования ответственным, истечение подтверждённой брони без отметки и автоматическая просрочка запроса без результата проверки к началу интервала.
- Уведомления по email о подтверждении, отклонении с причиной, отмене пользователем и истечении подтверждённой брони. Внешняя зависимость — почтовый сервис. Состояние брони хранится в РесурсБрони и доступно при сбое отправки.

Каталог ресурсов, часы доступности и роли заданы заранее. В первый семестр за рамками проекта остаются управление каталогом через интерфейс, ручное согласование, перенос и повторяющиеся брони, синхронизация с внешними календарями.

## Доменное ядро и тесты

Ядро — `src/ResourceBooking.Core` (.NET 8, без веб-фреймворка и драйвера БД): Job (`Bookings/`),
Tool и Registry (`Rules/`), Dispatcher и таймер (`Dispatching/`), хранение в памяти (`Storage/`).
Тесты — `tests/ResourceBooking.Core.Tests` (xUnit).

Запуск всех тестов одной командой из корня репозитория (нужен .NET 8 SDK):

```
dotnet test
```
